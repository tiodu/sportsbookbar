# sportsbookbar

Vite + React 18 + TypeScript (strict) + react-three-fiber + drei + Zustand + Howler + Vitest.

See [CLAUDE.md](./CLAUDE.md) for project structure and hard rules.

## Getting started

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — typecheck and build
- `npm run lint` — run ESLint
- `npm test` — run Vitest once
